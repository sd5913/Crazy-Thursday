# Food and dialogue asset packs

Three completed production packs from the team's artwork iteration. They are
standalone handoff archives; adding these files does not integrate or replace
anything in the game. No changes to the main page, game code, runtime catalogue,
or `main` branch are included.

| Pack | PNG items | Download | Contents |
| --- | ---: | --- | --- |
| Original set | 12 | [Original 12](Crazy-Thursday-food-and-dialogue.zip) | Congee, pudding, broccoli, cactus, sponge and other original objects; dialogue and previews. Already present in this branch. |
| Combined set | 54 | [Combined 54](feeding-assets-54-png-and-dialogue.zip) | The initial 24 plus 30 additional normal/surreal items; transparent PNGs, bilingual dialogue, JSON/CSV metadata and previews. |
| Clean odd set | 50 | [Clean odd 50](clean-odd-50-transparent-and-dialogue.zip) | Peculiar inedible objects and food/object combinations, avoiding mould-heavy imagery; transparent PNGs, bilingual dialogue, metadata and previews. |

There are 116 entries across the packs. Similar subjects can occur in different
packs; this is not a claim of 116 unique game items. Each pack keeps its original
IDs and metadata. The game's current integrated catalogue is maintained by the
technical team separately and may include a selected subset of these items.

PNG assets use transparent RGBA canvases. They were extracted generatively and
are not guaranteed pixel-identical to the original preview sheets. Treat
previews as references, not as runtime sprites. Some gameplay classifications
in the older metadata are provisional; review them before integrating.

Only completed transparent-image exports are included here. Later edible-food
preview sheets without completed individual exports are not included.
